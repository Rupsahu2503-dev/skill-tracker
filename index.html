Firebase प्रोजेक्ट कैसे सेट करें (स्टेप-बाय-स्टेप)

1. प्रोजेक्ट बनाएँ
  • console.firebase.google.com खोलें
  • “Add project” → नाम दें → Google Analytics optional → Create
2. Google Login चालू करें
  • Build → Authentication → Get started
  • Sign-in method → Google → Enable → Save
  • Settings → Authorized domains में localhost व अपना domain जोड़ें
3. Firestore बनाएँ
  • Build → Firestore Database → Create database
  • Test mode चुनें (बाद में rules लगाएँ) → Location → Enable
4. वेब ऐप रजिस्टर करें
  • Project settings → Your apps → </> Web
  • App nickname दें → Register → firebaseConfig कॉपी करें
5. नीचे दिए FIREBASE_CONFIG में पेस्ट करें
6. इसी फाइल में config ऐसे डालें: 
// index.html — <script> टैग में सबसे ऊपर
const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "skill-tracker-xxxx.firebaseapp.com",
  projectId: "skill-tracker-xxxx",
  storageBucket: "skill-tracker-xxxx.appspot.com",  // ← STORAGE के लिए ज़रूरी
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};

// ⚠️ storageBucket खाली होगा तो Image Upload काम नहीं करेगा।

Firebase Storage — इमेज अपलोड सेटअप

NEW
1. Storage चालू करें
  • Firebase Console → Build → Storage → Get started
  • अपना location चुनें (जैसे asia-south1 / us-central)
  • Security rules में Start in test mode → Enable
  • ऊपर Rules टैब → नीचे दिए rules पेस्ट करें → Publish
2. SDK जोड़ें (पहले से जुड़ा है)
  • firebase-storage-compat.js
  • config में storageBucket भरें
  • Upload flow: ref.put(file) → getDownloadURL() → Firestore में save
3. इस्तेमाल
  • Profile → फोटो बॉक्स पर क्लिक / ड्रैग
  • Project modal → कवर इमेज अपलोड
  • Progress bar दिखेगा → URL अपने आप फील्ड में भरेगा
Storage Security Rules (Rules टैब में पेस्ट करें) 
rules_version = '2';

service firebase.storage {
  match /b/{bucket}/o {

    // हर यूज़र सिर्फ अपनी folder में फाइल रख सकता है
    match /users/{uid}/{allPaths=**} {
      allow read: if true;   // public link के लिए
      allow write: if request.auth != null
                   && request.auth.uid == uid
                   && request.resource.size < 5 * 1024 * 1024
                   && request.resource.contentType.matches('image/.*');
    }

    // प्रोजेक्ट कवर इमेज
    match /projects/{uid}/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.uid == uid
                   && request.resource.size < 5 * 1024 * 1024
                   && request.resource.contentType.matches('image/.*');
    }
  }
}
Upload snippet (इसी फाइल में इस्तेमाल हुआ) 
// 1) Storage reference बनाएँ
const path = `users/${uid}/avatars/${Date.now()}_${file.name}`;
const ref  = firebase.storage().ref(path);

// 2) अपलोड + progress
const task = ref.put(file, { contentType: file.type });

task.on('state_changed',
  snap => setProgress(Math.round(snap.bytesTransferred / snap.totalBytes * 100)),
  err  => toast(err.message, 'err'),
  async () => {
    // 3) Public URL
    const url = await task.snapshot.ref.getDownloadURL();
    // 4) Firestore में save
    await db.collection('users').doc(uid).set(
      { profile: { avatar: url } }, { merge: true }
    );
  }
);
ध्यान दें: (1) storageBucket हमेशा <projectId>.appspot.com होता है। (2) बिना लॉगिन अपलोड नहीं होगा — पहले Google Login करें। (3) अगर firebase/storage is undefined दिखे तो firebase-storage-compat.js script ज़रूर लोड करें। (4) Blaze plan के बिना भी Storage free-tier पर चलता है।

Firestore डेटा मॉडल

users/{uid}/
  ├─ profile    { name, bio, avatar, cover, goal, tagline }
  ├─ skills/{skillId}   { name, tag, level, rating, hours, goal, color }
  ├─ routines/{rtId}    { title, time, icon, streak, history }
  ├─ tasks/{taskId}     { title, lang, starterCode, done }
  ├─ projects/{pjId}    { title, desc, tech[], link, img, status }
  └─ sessions/{ssId}    { date, skillId, minutes, note }

Storage:
  users/{uid}/avatars/…      → profile photo
  projects/{uid}/covers/…    → project cover

सब कुछ realtime — onSnapshot() से दूसरे डिवाइस पर तुरंत दिखेगा।
